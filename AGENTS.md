# Custom Instructions for AI Assistant

- **Gemini API Key Name**: In this project, the Gemini API key used on the client-side or within environment configuration is named `VITE_GEMINI_API_KEY` (instead of the default server-side `GEMINI_API_KEY`), which is loaded from the `.env` file via `import.meta.env.VITE_GEMINI_API_KEY` or process.env configuration.
